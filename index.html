🤖 Як увімкнути функції штучного інтелекту (ШІ)?
Оскільки файл працює локально на вашому комп'ютері, для роботи ШІ потрібен особистий безкоштовний ключ доступу. Ось як його отримати:
  1. Перейдіть на сайт aistudio.google.com (потрібно увійти через Google-акаунт).
  2. Натисніть кнопку "Create API key" (Створити API ключ).
  3. Скопіюйте згенерований довгий набір символів.
  4. Натисніть в програмі «✨ Офіційно» або «📝 Коректор» і вставте ключ у віконце, що з'явиться.
🔒 Ключ зберігається лише у вашому браузері і нікуди не передається. Якщо захочете змінити ключ, натисніть тут, щоб скинути налаштування.
